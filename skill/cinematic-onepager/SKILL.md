# Cinematic One-Pager (시네마틱 원페이지)

한 사람·한 브랜드·한 행사를 **휠을 내리면 살아 움직이는 한 페이지**로 만든다. 정보 나열이 아니라 **첫 3초에 한 감정을 각인**시키고, 스크롤로 그 감정을 전개하는 것이 목표다. 결과물은 항상 **단일 HTML 파일 + 바닐라 JS**(프레임워크·빌드·CDN 없음)로, 손으로 만든 듯 정교해야 한다.

## 절대 규칙 (셋 다 이걸 지켜서 고급스러워 보인다)

1. **순검정·순백 금지.** 배경은 푸른/따뜻한 기가 살짝 섞인 near-black, 텍스트는 off-white. 액센트는 **금속색 하나**(골드/플래티넘)를 주역으로, 선택적으로 보조색 하나(와인/버밀리언). *(2026-09-15 보강: 다크만 정답 아님. 업종에 따라 `~/.claude/design-refs/ui-style-picker-ko.md` 스타일 10종 중 하나를 고르고, 라이트면 종이색 #F2~#F7 + 잉크 알파 4단 + 액센트 1색. 필라테스·세무사·인테리어·헤어 레퍼런스 4개가 전부 라이트로 성공.)*
2. **토큰 우선.** 모든 색·폰트·이징·듀레이션·폭을 `:root` CSS 변수로. 하드코딩 색을 본문에 흩뿌리지 말 것.
3. **휠다운이 심장.** 정적 페이지는 실패다. 최소한 (a) 진입 연출 (b) 스크롤 리빌 스태거 (c) 스크롤 진행바 + **복합 저니 센터피스 1개**가 들어가야 한다. 저니 = 휠다운·가로 팬·빨려들어감(깊이)을 **섞은** 5~6컷 시퀀스(딱딱 끊기는 3컷 전환은 밋밋하니 피한다). → `references/motion.md`, 완성본은 `assets/template.html`
4. **덜어냄.** 폰트 2~3종, 액센트 1색, 문장 최소. 여백과 질감이 카피를 대신한다.
5. **`prefers-reduced-motion` 필수.** 모든 진입/리빌/핀 애니메이션은 reduced-motion에서 즉시 최종상태로. 게이트는 자동 개봉.
6. **한글 처리.** `word-break: keep-all`, KR 서브카피는 Noto Serif KR / Apple SD Gothic Neo, 라벨·숫자는 mono.

## 작업 순서

1. **주체·감정 정하기.** 누구/무엇인가? 심을 감정 하나는? (신뢰 / 특별함 / 압도 / 은밀함). 이게 팔레트·진입연출·복잡도를 결정한다.
2. **복잡도 티어 선택** (아래). 과욕 금물 — 티어2가 대부분의 정답.
3. **팔레트·타이포 고르기** → `references/palettes.md`, `references/typography.md`.
4. **스타터 템플릿 복제.** `assets/template.html`를 출력 위치로 복사해 시작한다. 이미 검증된 커널(토큰·리빌·진행바·핀 스크롤리텔링·그레인·reduced-motion)이 들어있다.
5. **콘텐츠·팔레트·진입연출 교체.** 섹션을 실제 내용으로, `:root` 색을 고른 팔레트로, 진입 연출을 티어에 맞게.
6. **모션 레시피 추가** → `references/motion.md`에서 필요한 것만 복붙(게이트/커서글로우/이미지 현상 등).
7. **반드시 브라우저로 검증.** 로컬 서버(`python3 -m http.server`)로 띄워 로더→히어로→스크롤→핀 전 구간 스크린샷. **`<meta charset="utf-8">` 없으면 한글 깨진다 — 항상 넣을 것.**

## 아키타입 (주제마다 골라라 — 이게 매크로 구조를 결정한다)

⚠️ **가장 중요한 규칙: 한 스켈레톤을 색만 바꿔 재탕하지 마라.** 주제가 다르면 진입 방식·섹션 순서·핵심 모션·타이포 무게가 **구조적으로** 달라야 한다. 베이커리와 영업사원이 "게이트→히어로→가로저니→숫자"로 똑같으면 실패다. 먼저 아키타입을 고르고, 그 안에서도 섹션 구성을 주제에 맞게 다시 짜라.

- **A. 초대장형** (TÀMH 초대장): **진입 게이트**(밀랍인장/케이크컷/명함 등 주제 사물) + 세리프(Cormorant+Noto Serif KR) + 다크 럭셔리 + 커서글로우 + 이미지 다크룸 현상 + 그레인. 세로 에디토리얼 리듬 or 저니. **초대장·프리미엄 브랜드·행사·개인 웹명함(감성)**. 절제·희소·은밀.
- **B. 스튜디오형** (IN STUDIO / instudio.kr): **% 로더 인트로**로 개봉 → **풀블리드 히어로**(컨덴스드 헤비 타이포 Anton/Black Han Sans) → **스펙 스트립**(SEOUL·SINCE·수치) → **클라이언트/산업 로고 마퀴 벽**(멀티행 스크롤) → 스크롤 케이스 리빌 → CTA. 소셜프루프·수치·압도가 핵심. **회사·스튜디오·에이전시·B2B 서비스·영업/실적형 개인**. → 로더는 `references/motion.md §10`, 마퀴는 §9.
- **C. 포트폴리오형** (박효균 포폴): 커튼 인트로 + **핀 고정 스크롤리텔링/WebGL**(스크롤로 터미널·궤도·3D 구동) + 커스텀 커서 + ⌘K + FLIP 모달 + 점진적 열화(3D→2D→정적). 기술 과시. **개발자·크리에이티브·기술 포트폴리오**. lazy-load+FPS강등+reduced-motion 필수.

혼합 가능(초대장 게이트 + 스튜디오 로고벽 등). 단 **한 곳에만 대담하고 나머지는 조용히**. 복잡도는 A<B<C 순으로 무거워지니 주제·목적에 맞는 최소로.

## 매크로 우선 (코드 전에)

레이아웃 짜기 전에 이 페이지만의 **구조 결정 4가지**를 먼저 정하라 — 두 페이지가 절대 같아지지 않게:
1. **진입**: 게이트(무슨 사물?) vs %로더 vs 커튼 — 주제 상징과 연결.
2. **핵심 모션 1개**: 가로 저니 / 세로 핀 스크롤리텔링 / 로고 마퀴 벽 / 풀블리드 교차 리빌 — 주제마다 다르게 고를 것.
3. **타이포 무게**: 얇은 세리프(초대장) vs 컨덴스드 헤비(스튜디오) vs 극대비(포트폴리오).
4. **섹션 순서·개수**: 주제 서사에 맞게. 템플릿 순서를 그대로 쓰지 말 것.

## 커널 (셋 다 공유하는 뼈대 — 템플릿에 이미 들어있음)

**구조 컨벤션:** 고정 배경 레이어(그레인/비네트) → 진입 연출 오버레이 → `#hero`(100dvh, 하단정렬, 거대 워드마크) → 넘버링 섹션들(`Nº 0X — TITLE` mono 아이브로 + 큰 display h2 + KR 서브) → 닫는 섹션/연락처 → footer(mono 라벨).

**타이포 시그니처:** display는 **좁은 자간**(`-.02em`~`-.05em`, 얇은 굵기 200~400 또는 극대비), 라벨은 **넓은 대문자 mono**(`.14em`~`.34em`, uppercase). 이 대비가 "에디토리얼 럭셔리"의 정체다. 크기는 전부 `clamp()` 유동. 숫자는 `tabular-nums`.

**ink=투명도 위계:** 텍스트 색 하나(예: `238,229,212`)를 4단계 알파(.93/.66/.40/.24)로. 색상 수가 아니라 투명도로 위계를 만든다. 라인도 동일.

**모션 어휘:** 이징 `--ease-expo: cubic-bezier(.16,1,.3,1)`. lerp 계수 커서 `.16`·트레일 `.34`·스크롤 `.1`·패럴랙스 `.045`. 리빌은 `.rv{opacity:0;transform:translateY(26px)}` → IntersectionObserver로 `.lit`, 요소별 `style="--d:120ms"` 스태거.

**이미지 규칙:** 절대 평면으로 두지 말 것. 히어로 이미지엔 방향성 스크림/비네트를 깔아 골드 텍스트가 뜨게. 스크롤 진입 시 `scale(1.07) brightness(.62)` → `scale(1) brightness(.86)` "현상".

**상태머신:** 진입은 `body` 클래스 토글로만(`sealed → open → done`). CSS가 애니메이션을 소유, JS는 클래스만 바꾼다. 바쁜 방문자용 탈출(wheel/touch/Enter `{once:true}`)과 reduced-motion 자동개봉 필수.

**자족성:** CSS·JS 100% 인라인. 장식 그래픽은 인라인 SVG/필터. 사진은 소량이면 base64 인라인, 많으면 로컬 파일(외부 CDN·서드파티 요청 금지). 폰트는 Google Fonts 링크 하나 또는 로컬 시스템 스택.

## 흔한 실수 (레퍼런스 제작 중 실제로 겪은 것)

- `<meta charset="utf-8">` 누락 → 로컬/일부 호스트에서 한글 mojibake. **항상 첫 줄에.**
- 진입 연출만 만들고 스크롤은 정적 → "이력서"가 됨. 휠다운 모션이 없으면 이 스킬의 존재 이유가 없다.
- 이펙트 남발 → 싸구려/AI스러움. 한 순간만 정확히 설계하고 나머지는 침묵.
- 액센트가 배경과 싸움 → 채도를 낮추거나 유사색으로. 골드는 near-black에서만 빛난다.
- 티어3를 이유 없이 선택 → 성능·유지보수 지옥. 기술 과시가 목적이 아니면 티어2.
- **폰 Safari 하단 툴바가 보이는 높이를 줄인다** → 핀 섹션에서 `bottom:`에 붙인 진행바·라벨이 본문과 겹침(얼라인 실사고). 모바일은 진행 UI를 내비 아래 `top:`에, 그림은 `max-width:calc(34svh * 비율)`로 높이에 묶고, **390×664·320×568에서 모든 진행도를 검사**. → `references/production.md §1`
- `.ln span` 같은 자손 선택자가 안쪽 장식 span까지 block으로 만듦 → 워드마크 마침표가 줄바꿈. 직계 `>` 사용. line-height<.9 + overflow:hidden이면 g·y 꼬리 잘림 → `padding-bottom:.22em;margin-bottom:-.18em`.
- 사진 없을 때 SVG 안 `<image>`/`<img>`가 깨진 아이콘을 크게 그림 → **로드 성공 후에만 삽입**. 사진 없이도 완성돼 보이는 폴백(선 그림·재질 패턴·이니셜) 필수.
- 밝은 사진 위 흰 제목 → 대비 부족. 방향성 그라디언트 + `brightness(.9)` + 약한 text-shadow를 사진 넣은 뒤 반드시 재확인.

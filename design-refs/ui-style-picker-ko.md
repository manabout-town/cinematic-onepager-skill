# UI 스타일 고르기 — 한국 업종별 매핑

**용도**: 클라이언트 원페이지/홈페이지 착수 전 "어떤 스타일로 갈지" 정하는 결정 레이어.
크래프트 수치는 여기 없다. 그건 `web-craft-baseline.md`(실측 타이포·간격·색), 스타일 구현 디테일은
`ui-ux-pro-max`의 `styles.csv`(79종, Best For / Do Not Use For / AI Prompt Keywords 컬럼 보유).

출처: 에이원 스튜디오(aewonstudio.com) "홈페이지 만들 때 고르는 UI 스타일 10가지" (Notion, 2026)
정리일 2026-09-12. 원문 표에 내 프로젝트 매핑과 styles.csv 검색어를 덧붙였다.

---

## 핵심 전제

스타일을 안 정하고 "예쁘게"라고 하면 결과물이 안 나온다. AI한테도 사람한테도 똑같다.
**"예쁜 것"이 아니라 "그 업종의 고객이 기대하는 것"을 고른다.** 안 맞으면 잘 만들어도 싸구려로 보이고,
맞으면 단순해도 전문가처럼 보인다.

---

## 그룹 A — 신뢰감·전문성이 먼저

고객이 "믿을 만한 곳인가"를 먼저 보는 업종. 화려함보다 정돈된 구조가 유리.

| 스타일 | 성격 | 한국 업종 | 레퍼런스 | csv 검색어 |
|---|---|---|---|---|
| 미니멀리즘 | 여백 넓게, 요소 덜어냄. 오래 봐도 안 질림 | 변호사·세무사·노무사, 컨설팅, B2B, 고가 서비스 | stripe.com | `minimal` |
| 에디토리얼 | 잡지 지면. 세리프 타이포 + 큰 사진. 글 많아도 고급 | 브랜드 스토리 중심, 디자인 스튜디오, 출판·문화, 웨딩 | kinfolk.com | `editorial` |
| 벤토 그리드 | 도시락 칸 카드 배치. 정보 많아도 안 복잡함 | 기능 많은 서비스, SaaS, 제품 소개 | apple.com | `bento` |

## 그룹 B — 세련·트렌디

"요즘 감각 있는 곳" 인상용. 효과가 강하니 포인트로만.

| 스타일 | 성격 | 한국 업종 | 레퍼런스 | csv 검색어 |
|---|---|---|---|---|
| 글래스모피즘 | 반투명 유리 질감. 어두운 배경 위 유리판 깊이감 | 테크, 앱 서비스, 프리미엄 브랜드 | authkit.com | `glass` |
| 그라디언트 메시 | 오로라처럼 번지는 배경. 사진 없이도 화면이 안 빔 | 테크, SaaS, 스타트업, 이벤트·커뮤니티 | partiful.com | `gradient` `aurora` |
| 다크모드 UI | 어두운 배경 + 포인트 컬러 하나. 배경만 바꿔도 규모감 | 테크, 개발, 크리에이티브, 나이트 업종(바·클럽) | vercel.com | `dark` |
| 뉴모피즘 | 배경과 같은 색 볼록 버튼. 부드럽지만 대비 낮음 | 웰니스, 헬스케어, 감성 앱 | neumorphism.io | `neumorph` |

⚠️ 그라디언트 메시는 색 조합에서 고급과 촌스러움이 갈린다. 뉴모피즘은 가독성이 약해 전면 적용은 비추,
버튼·카드 부분에만 쓰는 게 현재 추세.

## 그룹 C — 개성·임팩트

기억에 남는 게 신뢰보다 중요할 때. 타깃 불명확하면 역효과가 크다.

| 스타일 | 성격 | 한국 업종 | 레퍼런스 | csv 검색어 |
|---|---|---|---|---|
| 브루탈리즘 | 큰 타이포, 강한 대비, 날것 | 패션, 아트, 음악, 개인 브랜드 | flowen.me | `brutal` |
| 레트로·Y2K | 2000년대 감성. 픽셀, 형광 컬러 | 2030 타깃, 패션, F&B, 굿즈 | poolsuite.net | `retro` `y2k` |
| 3D·인터랙티브 | 스크롤·마우스 반응 3D. 체험형 | 제품 쇼케이스, 게임, 기술력 증명 | bruno-simon.com | `3d` `immersive` |

⚠️ 3D는 로딩 무거우면 이탈률이 올라간다. 모바일 성능 먼저 확인.

## AI에게 주문할 때 — 번역표

이 표가 이 문서의 실사용 핵심. 강의·교육자료에 그대로 쓸 수 있다.
**AI는 "예쁘게"를 모른다. "글래스모피즘"은 안다.**

| 이렇게 말하면 (실패) | 이렇게 바꾼다 (성공) |
|---|---|
| "깔끔하고 전문적으로" | "여백 넓은 미니멀 스타일로, 큰 제목과 흰 배경 중심으로" |
| "고급스럽게" | "다크모드에 포인트 컬러 하나만, 글래스모피즘 카드로" |
| "정보를 잘 정리해줘" | "벤토 그리드 레이아웃으로 카드를 나눠서" |
| "친근한 느낌으로" | "밝은 그라디언트 배경에 둥근 모서리 카드로" |

패턴: **[스타일명] + [배경 처리] + [주요 컴포넌트 형태]** 세 조각을 항상 붙인다.

---

## 선택 규칙 5개 (상담 체크리스트)

1. **업종 기대치 우선.** 법률 사무소에 Y2K는 아무리 잘 만들어도 신뢰가 안 생긴다.
2. **스타일은 하나로 통일.** 두세 개 섞으면 정리 안 된 인상.
3. **가독성이 항상 위.** 효과가 글씨를 방해하면 그 효과를 뺀다.
4. **모바일 먼저 확인.** 방문자 대부분이 폰.
5. **경쟁사 3곳 먼저 본다.** 다 비슷하면 다르게 가고, 제각각이면 가장 깔끔한 쪽으로.

5번이 상담에서 제일 잘 먹히는 문장. 클라이언트가 스스로 근거를 납득한다.

## 2026 흐름 5가지

| 흐름 | 내용 |
|---|---|
| 레이어와 깊이감 | 블러·반투명·은은한 그림자로 층 만들기. 글래스모피즘/그라디언트 메시가 여기 속함 |
| 스크롤텔링 | 스크롤에 따라 요소가 순서대로 등장. 브랜드 소개에서 특히 강함 |
| 마이크로 인터랙션 | hover·press의 미세한 반응. 완성도 차이가 여기서 갈림 |
| Y2K·레트로 재등장 | 픽셀·도트·게임 화면. 젊은 타깃에서 활발 |
| 유동형 레이아웃 | 고정 그리드 대신 화면 크기에 맞춰 흐르듯 변형 |

전부 따라갈 필요 없다. 업종에 맞는 하나만 제대로.

## 내 프로젝트 역매핑

기존 작업물이 어느 칸에 있는지. 새 클라이언트 상담 때 "이런 느낌"으로 보여줄 사례로 쓴다.

| 프로젝트 | 스타일 | 비고 |
|---|---|---|
| 고즈바이 (웨딩 본식스냅) | 에디토리얼 | 먹+금박+인주, 청첩장 방향 |
| TÀMH 포트폴리오 (위스키바 영업) | 에디토리얼 + 다크 | 밀랍인장 개봉 |
| 레포사 메뉴판 (데낄라 바) | 다크모드 | 나이트 업종 정석 |
| 포트폴리오 (우주 톤) | 다크 + 3D·인터랙티브 | 시네마틱 휠스크롤 |
| 유라연 (수제 헤어핀) | 미니멀 | 모노 3색 |
| 프차픽 / fablev8 | 벤토 그리드 | 정보량 많은 대시보드형 |

**빈칸 = 아직 안 해본 것**: 브루탈리즘, 레트로·Y2K, 뉴모피즘, 그라디언트 메시.
포트폴리오 다양성 필요하면 이 넷 중에서 고른다.
